# Pydantic Schemas

## Files
- `__init__.py`: Package initialization.
- `mcp.py`: MCP tool call schemas (JSON-RPC request/response, create_checkout_order params).
- `validation.py`: Validation result schemas (flags, reasons, risk score, action type).
- `razorpay.py`: Razorpay request/response schemas (Order, PaymentLink, Webhook payload).
- `dashboard.py`: Dashboard/CLI output schemas for visualization.
